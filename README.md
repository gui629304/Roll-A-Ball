## Sobre o projeto

Roll a Ball é um jogo simples em que o jogador controla uma esfera em um cenário 3D. O objetivo é coletar todos os itens espalhados pelo mapa enquanto movimenta a bolinha pelos obstáculos. O projeto foi desenvolvido para praticar conceitos básicos da Unity e programação em C#. Quando todos os itens são coletados, o jogo exibe uma mensagem de vitória.

## O que o projeto faz

- O jogador movimenta a bolinha usando o teclado.
- Os itens coletáveis desaparecem ao serem tocados.
- A pontuação aumenta conforme os itens são coletados.
- Uma mensagem de vitória aparece quando todos os itens são coletados.

## O que o projeto contém

- **Cenas:** MiniGame
- **Scripts:**
  - `PlayerController.cs` – controla a movimentação do jogador.
  - `CameraController.cs` – faz a câmera acompanhar o jogador.
- **Objetos principais:**
  - Player
  - Ground
  - Walls
  - PickUp
- **Recursos usados:**
  - Rigidbody
  - Collider (Is Trigger)
  - TextMeshPro
  - Física da Unity

## Controles

- **W / A / S / D** – movimentar a bolinha
- **Setas do teclado** – movimentar a bolinha

## O que eu aprendi

Neste projeto aprendi a criar scripts em C# para controlar objetos na Unity. Também aprendi a utilizar Rigidbody para movimentação baseada em física, colisões com Trigger e atualização de elementos da interface de usuário. Além disso, pratiquei a organização de cenas e componentes dentro da Unity.
